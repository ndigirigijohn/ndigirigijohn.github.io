QuoteKamili

AI quoting for trade and industrial suppliers, from electrical and plumbing to building materials and metals. It turns emails, PDFs, scans and photos of handwritten lists into priced quotes in under a minute.

  • The AI only reads the request. Prices, fees, totals and unit conversions run in tested code, and supplier pricing never goes to a model.

How I build with AI

I use AI agents to ship faster, and I keep AI inside products on a short leash. Both follow one rule: nothing is trusted until it is checked.

  1. 01

    Spec first, small slices.

    Every feature starts as a written spec with acceptance criteria. Agents, mainly Claude Code and often several in parallel, build it in small, reviewable slices.

  2. 02

    Verified, not trusted.

    Agent-written code passes the same gates as mine: type checks, dependency boundaries, property-based tests, real-browser and accessibility tests.

  3. 03

    AI reads, code decides.

    In products, models read and suggest. Tested code handles money and data, and a person approves anything customer-facing.

  4. 04

    A maintained agent setup.

    A reusable configuration of conventions, checks and review rules, connected to tools over MCP and updated as models change.
