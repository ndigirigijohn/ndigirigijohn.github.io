## You're looking at the build, not the source

Everything in this repo is generated. The site is written in React and TypeScript in a private repo, prerendered to static HTML, and published here with one command:

```
npm run deploy:pages
```

Each deploy replaces every file, so there's nothing here to edit by hand. The commit message names the source commit it was built from.

## What's in the box

| Path | What it is |
| --- | --- |
| `index.html`, `work/`, `about/`, `writing/`, `contact/` | Every page, prerendered: readable without JavaScript, then taken over by React |
| `assets/` | JavaScript and CSS, with a content hash in each file name |
| `og-default.png`, `og/` | Link-preview images, including one for each post |
| `404.html` | The app itself, so unknown addresses still reach the site's own 404 page |
| `sitemap.xml`, `robots.txt` | For search engines |
| `resume.pdf` | My résumé |
